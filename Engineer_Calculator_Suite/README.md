# Engineering Calculator Suite

A collection of Python-based engineering calculators developed to perform common calculations encountered in mechanical engineering and engineering analysis.

The project combines multiple calculators into a single engineering toolkit.

---

## Calculators Included

### Reynolds Number Calculator

Calculates Reynolds Number and classifies flow as:

* Laminar
* Transitional
* Turbulent

### Beam Stress Calculator

Computes normal stress using applied force and cross-sectional area.

### Factor of Safety Calculator

Evaluates design safety based on allowable and applied stresses.

### Spring Force Calculator

Implements Hooke's Law to determine spring force for a given displacement.

### Pump Power Calculator

Calculates hydraulic power requirements using flow rate, fluid density, and head.
